# RCWL-0516 레이더 센서 결선도

## 핀 연결 (4핀 소켓 쉴드 - PIN 3~6)

| 색상 | Pi 핀 | BCM   | RCWL 핀 | 신호       |
|------|-------|-------|---------|------------|
| 빨강 | PIN 4 | 5V    | VIN     | 5V 전원    |
| 검정 | PIN 6 | GND   | GND     | 접지       |
| 주황 | PIN 5 | GPIO3 | OUT     | 감지 신호  |
| -    | PIN 3 | GPIO2 | -       | 미연결     |

## ASCII 결선도

```
Raspberry Pi GPIO (PIN 3~6)     RCWL-0516
┌────┬────┬────┬────┐           ┌──────────────────┐
│PIN3│PIN4│PIN5│PIN6│           │3V3 GND OUT VIN CDS│
│ -  │ 5V │IO3 │GND │           │ x   │   │   │  x │
└────┴────┴────┴────┘           └─────┼───┼───┼────┘
      │         │                     │   │   │
      │(빨강)5V └───────────────────────────────► VIN
      │(검정)GND────────────────────► GND
      └(주황)GPIO3──────────────────────────► OUT
```

## 소프트웨어 설정

- GPIO 핀: BCM3 (물리 PIN 5)
- 감지: RISING edge (HIGH = 감지)
- 디바운스: 300ms
- 홀드타임: ~2~3초 (하드웨어 특성)
