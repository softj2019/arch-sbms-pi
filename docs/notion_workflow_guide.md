## 시스템 한눈에 보기

SBMS는 버스 승강장에서 **휠체어·목발 사용자를 자동으로 감지**하고, 버스 기사에게 **LED 전광판으로 알림**을 보내는 스마트 시스템입니다.

```
[카메라 + 레이더]
      ↓
  [AI 분석]  ← 휠체어·목발 사용자 인식
      ↓
[중앙 제어 장치]
      ↓
[LED 전광판]  ← 버스 기사에게 "교통약자 승차대기" 알림
      ↓
  [서버 연동]  ← 관리 센터 실시간 모니터링
```

### 핵심 기능 요약

| 기능 | 설명 |
|------|------|
| 교통약자 감지 | 카메라 AI가 휠체어·목발 사용자를 자동 식별 |
| 승차대기 알림 | LED 전광판에 "교통약자 승차대기" 메시지 표시 |
| 버스 기사 안내 | 정류장 접근 전 사전 준비 가능 |
| 원격 모니터링 | 관리 서버에서 실시간 상황 확인 |
| 오탐 방지 | 배경 물체·벽 등 잘못된 감지를 AI가 자동 필터링 |

## 교통약자 감지 워크플로우

### 전체 흐름

```
1. 카메라가 촬영
      ↓
2. AI 모델 1 (사람 감지)
   └─ 사람·자전거·오토바이 인식 (휠체어 사용자 포함)
      ↓
3. AI 모델 2 (교통약자 전용)
   └─ 휠체어 / 목발 인식
      ↓
4. 동시 감지 확인
   ├─ 사람 + 교통약자 기기 → ✅ 유효한 감지
   └─ 교통약자 기기만 → ❌ 오탐으로 무시
      ↓
5. 면적 필터 (오탐 방지)
   ├─ 화면의 20% 이하 → ✅ 통과 (실제 사람 크기)
   └─ 화면의 20% 초과 → ❌ 배경 물체로 판단, 무시
      ↓
6. 감지 확정
   └─ LED 알림 + 서버 전송
```

### AI 이중 모델 구조

> **왜 AI 모델을 두 개 사용하나요?**
>
> 하나의 AI 모델만 사용하면 일반 자전거나 오토바이를 교통약자로 잘못 감지할 수 있습니다. 두 모델을 동시에 사용하여 **"사람이 있고, 그 사람이 교통약자 기기를 사용하는 경우"만** 알림을 보냅니다.

| AI 모델 | 역할 | 감지 대상 |
|---------|------|-----------|
| 범용 모델 (COCO) | 사람 존재 여부 확인 | 사람, 자전거, 오토바이 |
| 전용 모델 (교통약자) | 기기 종류 식별 | 휠체어, 목발 |

### 오탐 방지 로직

**문제 상황 예시:**
- 버스 정류장 뒤쪽 창고에 놓인 자전거나 휠체어가 감지되는 경우
- 배경에 고정된 물체가 AI에게 교통약자 기기로 보이는 경우

**해결 방법 — 면적 필터:**

```
화면 전체 면적 대비 감지 객체 크기 계산

실제 휠체어 사용자: 약 9~10% (적당한 크기) → ✅ 유효
배경 오탐 물체:    약 29~30% (너무 크다) → ❌ 제외
```

## 승차대기 알림 워크플로우

### LED 전광판 메시지 단계

교통약자가 감지되면 LED 전광판이 다음 순서로 동작합니다:

```
[교통약자 감지]
      ↓
① 점등: "교통약자 승차대기"
   └─ 버스 기사에게 즉시 알림
      ↓
② 유지: 사람이 있는 동안 계속 표시
   └─ 3프레임 연속 감지 실패 시 해제
      ↓
③ 소등: 버스 출발 또는 탑승 완료
   └─ 자동 리셋
```

### 감지 신뢰도 기준

> 한 번의 감지만으로는 알림을 보내지 않습니다. 연속된 감지를 통해 오탐을 줄입니다.

| 상태 | 조건 | 동작 |
|------|------|------|
| 감지 시작 | 교통약자 + 사람 동시 감지 | LED 점등, 서버 알림 |
| 감지 유지 | 계속 감지됨 | LED 유지 |
| 감지 해제 | 3프레임 연속 미감지 | LED 소등, 상태 초기화 |

### 센서 융합 (카메라 + 레이더)

> 카메라만 사용하면 야간, 역광, 안개 등 환경에 취약합니다. 레이더를 함께 사용하여 신뢰성을 높입니다.

```
[카메라 감지] + [레이더 감지]
         ↓
     두 신호 비교
    ┌────┴────┐
  둘 다 감지   하나만 감지
    ↓            ↓
  강한 확정    보조 참고용
```

| 운용 모드 | 설명 |
|-----------|------|
| CAMERA 모드 | 카메라만 사용 |
| RADAR 모드 | 레이더만 사용 |
| FUSION 모드 | 카메라 + 레이더 동시 사용 (권장) |

## 하드웨어 구성 요소

### 승강장 설치 장치

```
┌─────────────────────────────────┐
│         버스 승강장              │
│                                  │
│  [카메라]  [레이더]              │
│     ↘       ↙                   │
│    [라즈베리파이]  ← 중앙 제어   │
│         ↓                        │
│    [LED 전광판]  ← 버스 기사용  │
│         ↓                        │
│    [냉각팬]     ← 온도 관리     │
└─────────────────────────────────┘
```

| 장치 | 역할 |
|------|------|
| IP 카메라 | 실시간 영상 촬영 (RTSP 스트리밍) |
| 마이크로파 레이더 | 사람 존재·움직임 감지 (야간·악천후 보조) |
| 라즈베리파이 | AI 처리 및 전체 시스템 제어 |
| LED 전광판 (M10) | 버스 기사용 교통약자 알림 표시 |
| 냉각팬 | 여름철 장치 과열 방지 |

### 외부 연결

```
[승강장 라즈베리파이]
         ↓ (인터넷)
[관리 서버: 175.45.215.53]
         ↓
[관리자 대시보드 / 모니터링]
```

## 주요 운영 모드

### 센서 모드 설정

| 모드 이름 | 동작 방식 | 적합 환경 |
|-----------|-----------|-----------|
| `SENSOR_MODE=camera` | 카메라 AI만 사용 | 야간 조명 충분, 맑은 날 |
| `SENSOR_MODE=radar` | 레이더만 사용 | 카메라 고장 또는 개인정보 이슈 |
| `SENSOR_MODE=both` | 카메라 + 레이더 | 일반 운용 (권장) |

### 융합 판단 방식

| 방식 | 설명 | 특성 |
|------|------|------|
| `FUSION_MODE=gating` | 레이더가 먼저 감지해야 카메라 AI 실행 | 전력 절약, 빠른 반응 |
| `FUSION_MODE=confirm` | 카메라 감지 후 레이더로 교차 검증 | 높은 신뢰도, 오탐 감소 |

## 시스템 상태 모니터링

### 실시간 데이터 전송 항목

관리 서버는 아래 정보를 실시간으로 수신합니다:

| 데이터 | 설명 |
|--------|------|
| `mobility_visible` | 교통약자 현재 감지 여부 (true/false) |
| `count` | 감지된 교통약자 수 |
| `mobility_type` | 종류 (Wheelchair / Crutch) |
| `confidence` | AI 감지 신뢰도 (0.0~1.0) |
| `led_on` | LED 전광판 현재 상태 |
| `radar_presence` | 레이더 감지 상태 |

### 알림 채널 (STOMP 토픽)

| 토픽 | 내용 |
|------|------|
| `/api/iot/mobility` | 교통약자 감지 정보 |
| `/api/iot/hid` | 사람 존재 여부 (레이더 기반) |
| `/api/iot/overview` | 전체 시스템 요약 상태 |

## 자주 묻는 질문

### Q. 야간이나 비 오는 날도 작동하나요?

**A.** 네, 레이더 센서가 함께 작동하기 때문에 어두운 환경이나 악천후에도 감지가 가능합니다. 단, 카메라 단독 모드(`SENSOR_MODE=camera`)로 설정된 경우에는 조명이 필요합니다.

---

### Q. 일반 자전거 타는 사람이 감지되지 않나요?

**A.** AI가 두 단계로 확인합니다.
1. 사람이 있는지 확인
2. 실제 휠체어·목발 기기가 보이는지 확인

두 조건이 모두 만족될 때만 알림을 보냅니다. 단순히 자전거를 타거나 카트를 미는 사람은 감지되지 않습니다.

---

### Q. 배경에 있는 물체가 오탐될 수 있나요?

**A.** 면적 필터를 적용하여 화면의 20% 이상을 차지하는 물체는 배경으로 판단해 무시합니다. 실제 사람이 탄 휠체어는 약 9~10% 정도 차지하므로 정상 감지됩니다.

---

### Q. LED 전광판은 어떤 메시지를 표시하나요?

**A.** 교통약자가 감지되면 M10 LED 전광판에 **"교통약자 승차대기"** 메시지를 표시합니다. 탑승이 완료되거나 더 이상 감지되지 않으면 자동으로 소등됩니다.

---

### Q. AI 모델은 얼마나 정확한가요?

**A.** 현재 배포된 모델 기준:
- 휠체어 감지 신뢰도 임계값: **60% 이상** (운영 환경)
- 오탐 방지를 위해 데이터 수집 및 파인튜닝을 지속 진행 중
- 수집 목표: **1,000장 (100장 × 10세트)** 현장 데이터
